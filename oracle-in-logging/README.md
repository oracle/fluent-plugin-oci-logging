# Oracle Cloud Infrastructure Fluentd Plugin

This is the official [fluentd](https://docs.fluentd.org/) plugin for the Oracle
Cloud Infrastructure (OCI) Logging service. This project is open source, in
active development and maintained by Oracle.

## Installation

Download the gem in your ruby environment:

```
wget https://raw.githubusercontent.com/oracle/fluent-plugin-oci-logging/refs/heads/logging-input-plugin-v0.1-beta/oracle-in-logging/fluent-plugin-oracle-in-logging-v0.1-beta.gem
```

Install the gem:

```
gem install fluent-plugin-oracle-in-logging-v0.1-beta.gem
```
## Documentation

Full documentation, including prerequisites, and configuration instructions can be found in the README file inside the gem folder, after you install the plugin.
